# 🎓 EDUPlus – AI-Powered Skill Learning Platform

An intelligent web platform that helps users learn new skills by generating **personalized learning resources and project ideas** using AI.

---

## 🚀 Overview

**EDUPlus** is a modern React-based web application that leverages **AI + REST APIs** to provide tailored learning paths. Users can select a skill, and the platform dynamically suggests:

* 📺 Curated YouTube learning resources
* 💡 Project ideas based on skill level
* 📈 Structured learning approach

---

## ✨ Features

* 🤖 **AI-Powered Recommendations**
  Generates personalized learning content using API integration

* 🎯 **Skill-Based Learning**
  Users select skills and get tailored resources instantly

* 📺 **YouTube Integration**
  Fetches relevant tutorials dynamically

* 💡 **Project Suggestions**
  AI-generated project ideas to reinforce learning

* ⚡ **Fast & Responsive UI**
  Built with React for smooth user experience

---

## 🛠️ Tech Stack

* **Frontend:** React.js, JavaScript
* **State Management:** React Hooks (`useState`, `useEffect`)
* **API Integration:** REST APIs
* **Deployment:** Netlify

## ⚙️ Installation & Setup

### 🔧 Prerequisites

* Node.js (v14 or above)
* npm or yarn

---

### ▶️ Steps to Run Locally

1. **Clone the repository**


2. **Navigate to project directory**

```id="fd9c4r"

```

3. **Install dependencies**

```id="v4k6ys"

```

4. **Start development server**

```id="0ks6df"

```

5. Open in browser:


## 💡 How It Works

1. User selects a skill (e.g., Web Development, AI, etc.)
2. App sends request via REST API
3. AI processes input and returns:

   * Learning resources
   * YouTube videos
   * Project ideas
4. Results are dynamically displayed
